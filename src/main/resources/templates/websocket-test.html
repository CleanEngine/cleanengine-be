데이터 문제 원인 분석

전일 대비 데이터가 모두 0.0으로 표시되는 이유:

  1. 데이터베이스에 어제 및 현재 거래 데이터가 없음
  2. RealTimeDataPrevRateService.java의 generatePrevRateData 메서드에서 DB 쿼리 결과가 null
  3. 그 결과 데이터 모두 0.0으로 초기화된 PrevRateDto 객체 반환

해결 방법: 실시간 거래 데이터(price 값이 있음)를 활용하여 전일 대비 데이터 대체
